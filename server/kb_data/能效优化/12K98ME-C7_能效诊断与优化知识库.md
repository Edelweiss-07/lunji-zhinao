### 4.2 PMI系统监测参数

PMI（Pressure Analyser）系统实时监测每缸：
- **Pmax**（爆发压力）：各缸独立监测，自动平衡
- **Pcomp**（压缩压力）：各缸独立监测
- **Pi**（平均指示压力）：计算值
- **PT图/PV图**：实时示功图
- **压缩比**：C.Ratio = Pcomp / Pscav（Pscav校正为绝对值+1bar大气压）

## 5. 诊断规则库

### 5.1 高油耗低效工况识别

| 规则ID | 诊断条件 | 结论 | 依据 |
|--------|---------|------|------|
| D-001 | 当前负荷 < 50% MCR 且持续运行 | 低负荷低效区，SFOC>170 g/kWh | 台架数据：25%负荷SFOC=181.11 |
| D-002 | 当前负荷 > 95% MCR 且持续运行 | 高负荷低效区，SFOC上升 | 台架数据：100%负荷SFOC=175.39，110%=179.00 |
| D-003 | 当前负荷在70%~85%区间 | 经济运行区间，SFOC最低 | 台架数据：75%负荷SFOC=168.64 |
| D-004 | 实测SFOC > 同负荷台架基准 + 5 g/kWh | 存在性能衰减或异常，需排查 | 台架基准+容差 |
| D-005 | 实测SFOC > 同负荷台架基准 + 10 g/kWh | 严重性能衰减，立即检查增压器/空冷器/燃油阀 | 经验阈值 |

## 6. 优化规则库

### 6.1 经济运行区间优化

| 规则ID | 优化建议 | 预期效果 | 约束条件 |
|--------|---------|---------|---------|
| O-001 | 维持主机负荷在 **70%~85% MCR** 区间运行 | SFOC最低（约168-171 g/kWh） | 需满足航次计划 |
| O-002 | 避免长期低于50%负荷运行 | 避免低油耗恶化（>170 g/kWh） | 机动航行除外 |
| O-003 | 避免长期高于95%负荷运行 | 避免高负荷油耗上升 | 海况良好时 |
| O-004 | 根据航次计划选择经济航速 | 降低总燃油消耗 | 考虑船期约束 |

### 6.2 Pmax调谐优化

| 规则ID | 优化建议 | 预期节油 | 操作方式 |
|--------|---------|---------|---------|
| O-010 | 将平均Pmax提升至接近设计值（约150 bar） | 每bar 0.20-0.30 g/kWh | 调整燃油喷射正时（VIT） |
| O-011 | 启用PMI Auto-tuning自动调谐 | 典型0.5-1 g/kWh，最大3 g/kWh | MOP上启用自动调谐 |
| O-012 | Pmax提升潜力5-10 bar（纯提升） | 1.0-3.0 g/kWh | 逐步提升，监控ΔP≤35 bar |
| O-013 | 气缸平衡+Pmax提升额外2-5 bar | 0.4-1.5 g/kWh | PMI平衡各缸后再提升 |
| O-014 | 低负荷时也可进行Pmax调谐 | 全负荷范围有效 | 自动调谐支持 |

> **重要约束**：Pmax - Pcomp ≤ 35 bar（硬限制），调谐时必须监控

> **来源**：PMI & EDS培训第3、18、25页

### 6.3 气缸平衡优化

| 规则ID | 优化建议 | 操作方式 |
|--------|---------|---------|
| O-020 | 各缸Pmax偏差控制在±3 bar内 | PMI自动平衡 / 手动偏移调整 |
| O-021 | 各缸Pcomp偏差控制在±3 bar内 | 调整压缩比偏移(C.Ratio Offset) |
| O-022 | 各缸Pi偏差控制在±5%内 | 调整燃油指数偏移 |
| O-023 | 高负荷和低负荷分别设置Pi偏移 | 低负荷额外平衡需求 | MOP设置 |
| O-024 | 独立气缸Chief限制器设置最大燃油 | 防止单缸过载 | Fuel System培训第13页 |

> **调谐流程**： Retrieve pressures → Extract key values → Identify Pcomp/Pi/Pmax adjust → Apply offsets → Tuned engine → Continuous auto tuning
> **来源**：PMI & EDS培训第12-16、19页

### 6.4 燃油喷射正时优化

| 规则ID | 优化建议 | 效果 |
|--------|---------|------|
| O-030 | 提前喷射正时→Pmax升高→油耗降低 | 对应MC机VIT调整 |
| O-031 | 延迟喷射正时→Pmax降低→NOx降低 | Emission模式 |
| O-032 | Economy模式 vs Emission模式切换 | 经济模式优先油耗，排放模式优先NOx |

## 8. 计算公式与校正方法

### 8.1 比油耗(SFOC)计算

```
SFOC (g/kWh) = 燃油消耗量(kg/h) × 1000 / 有效功率(kW)
```

**前提条件**：
- 已知发动机功率和一段时间内的燃油消耗量
- 流量计法：测量时长≥1小时
- 日柜法：消耗整柜时间
- 必须在平静天气条件下测量

> **来源**：01. OPERATION & DATA.pdf 第437页（706-02节）

### 8.2 燃油消耗量换算

```
燃油量(kg) = 测量体积(L) × 密度(kg/L)
```

- 密度需对应测量点温度
- 密度可通过比重计(hydrometer)测量或根据燃油规格计算
- 燃油规格通常给出15℃/60°F时的比重
- 实际密度根据Plate 70611温度-密度曲线修正

> **来源**：01. OPERATION & DATA.pdf 第437页

### 8.3 低热值(LCV)校正

```
校正后SFOC = 实测SFOC × (实际LCV / 10200 kcal/kg)
```

- 台架标准：10200 kcal/kg（=42707 kJ/kg，对应气油）
- 船用燃油LCV通常未指定，可根据硫含量和15℃比重通过Plate 70611曲线确定
- 目的：使不同燃油品质下的油耗测量结果可比

> **来源**：01. OPERATION & DATA.pdf 第437页

### 8.4 指示功率计算

```
Pi (kW) = k2 × n × pi
其中：
  k2 = 1.30900 × D² × S  (D=缸径m, S=行程m)
  n = 主机转速(rpm)
  pi = 平均指示压力(bar) = 示功图面积 / (示功图长度 × 弹簧常数)
```

### 8.5 有效功率计算

```
Pe (kW) = k2 × n × pe
其中：
  pe = pi - k1  (k1=平均摩擦损失，约1 bar)
```

### 8.6 轴功率

```
轴功率 ≈ 有效功率 × (1 ~ 0.99)
```
- 推力轴承摩擦导致轴功率比有效功率低最多1%
- 取决于转速负荷和FPP/CPP类型

> **来源**：01. OPERATION & DATA.pdf 第448-449页（706-05节）

### 8.7 压缩比计算（PMI用）

```
C.Ratio = Pcomp / Pscav_absolute
Pscav_absolute = Pscav_sensor + 1 bar (大气压)
C.Ratio Offset = 偏移量 / Pscav_absolute
```

> **来源**：PMI & EDS培训第12页

### 8.8 碳排放估算（间接法）

```
CO2排放量(kg) = 燃油消耗量(kg) × 碳排放因子
```
- HFO碳排放因子约3.114 kg CO2/kg燃油（IMO默认值）
- MGO碳排放因子约3.206 kg CO2/kg燃油
- 可根据SFOC和功率计算：CO2 (g/kWh) = SFOC × 碳排放因子

> **注意**：本知识库文件中无直接碳排放数据，此为行业通用公式，供智能体间接核算使用

### 12.1 SEEMP（船舶能效管理计划）

**法规依据**：IMO MARPOL附则VI第22条；MEPC.213(63) 2012年SEEMP指南；**MEPC.346(78) 2022年SEEMP指南**（2023年1月1日生效）

**SEEMP三部分结构（2022年强化版）**：

| 部分 | 定义 | 适用 | 核心内容 |
|------|------|------|---------|
| **Part I** | 提升船舶能效的管理计划 | 所有400总吨以上船舶 | 计划、实施、监测、自我评估和改进的管理体系 |
| **Part II** | 船舶能效管理计划描述 | 2023.1.1起，适用EEXI的船舶 | EEXI计算、达标措施、所需EEXI验证 |
| **Part III** | 船舶营运碳强度计划 | 2023.1.1起，5000总吨以上船舶 | CII目标、实施计划、自我评估、整改措施 |

**SEEMP四步循环（MEPC.346(78)第3条）**：
1. **计划(Planning)**：识别能效改进机会，制定措施和目标
2. **实施(Implementation)**：执行能效措施，分配职责和资源
3. **监测(Monitoring)**：收集燃油消耗、航程、货运量等数据
4. **自我评估和改进(Self-evaluation & improvement)**：定期评估能效绩效，持续改进

**SEEMP核心要素（Part I）**：
- 能效方针与目标
- 职责与权限（指定船舶能效管理负责人）
- 能效相关操作程序（航次规划、航速优化、主机优化、船体维护、辅机管理等）
- 监测与测量（燃油消耗、航程、货运量、航行小时数）
- 不符合与纠正措施
- 记录与报告
- 内部审核与管理评审
- 持续改进机制
- 船员培训与意识

**与主机能效诊断的关联**：
- SEEMP要求船舶建立**燃油消耗监测机制**，本知识库第2-8章提供主机层面的油耗基准、诊断规则和优化方法
- SEEMP要求**能效改进措施**，本知识库第6章优化规则库可直接支撑措施制定
- SEEMP要求**自我评估与改进**，本知识库第5章诊断规则可支撑定期能效评估

### 12.2 EEXI（现有船舶能效指数）

**法规依据**：IMO MEPC.328(76) 2021年通过，2023年1月1日生效

**适用范围**：400总吨及以上的现有船舶（散货船、油船、集装箱船、杂货船、客船等）

**EEXI计算公式**：

```
EEXI = (CFME × P_ME + CFAE × P_AE) / (Capacity × f_j × f_i × f_c × f_l)
```

其中：
- **CFME**：主机碳排放因子（gCO2/g燃油），HFO取3.114；主机默认SFC：二冲程175g/kWh，四冲程200g/kWh
- **P_ME**：主机功率（kW），按75%MCR计算（限制后功率）
- **CFAE**：辅机碳排放因子，取3.114
- **P_AE**：辅机功率（kW）
- **Capacity**：船舶载重吨/容积吨
- **f_j**：主机功率降低系数（EPL/轴功率限制）
- **f_i**：推进系统创新能效系数
- **f_c**：货舱容积系数
- **f_l**：滚装船/客船系数

**EEXI达标措施**：

| 措施 | 原理 | 对主机的影响 |
|------|------|------------|
| **EPL（发动机功率限制）** | 限制主机最大输出功率至75%MCR以下 | 直接降低P_ME，本知识库负荷图可验证限制后运行边界 |
| **轴功率限制（ShaPoLi）** | 限制轴输出功率 | 类似EPL，不限制主机本身 |
| **替代燃料** | 使用LNG/甲醇/氨等低碳燃料 | 降低CFME |
| **节能技术** | 风帆、气泡减阻等 | 降低所需功率 |
| **推进效率提升** | 螺旋桨优化、船体线型改造 | 降低相同航速下的主机负荷 |

**与本知识库的关联**：
- EPL措施下，主机最大负荷被限制，本知识库第2章台架数据可计算限制后的SFOC
- 本知识库第9章运行边界可验证EPL限制后主机是否仍在安全运行区间
- 本知识库第6章优化规则可在EPL限制范围内进一步优化油耗

### 12.3 CII（碳强度指标）

**法规依据**：IMO MEPC.329(76) 2021年通过，2023年1月1日生效

**CII定义**：单位运输工作量的CO2排放量（gCO2/(dwt·n mile)）

**CII计算公式（MEPC.328(76)附则IX第4条）**：

```
年度营运CII = Σ(FCj × CFj) / (C × Dt)

其中：
  FCj = 年度内j类燃油消耗量 (g)
  CFj = j类燃油的碳排放因子 (gCO2/g燃油)
  C   = 船舶载重吨 (dwt) 或容积吨
  Dt  = 年度内船舶在海上航行的距离 (n mile)
```

**CII评级计算**：
```
CII评级系数 = 年度营运CII / 所需年度CII参考值
```
- 评级系数 ≤ 0.80 → **A级**
- 0.80 < 评级系数 ≤ 0.94 → **B级**
- 0.94 < 评级系数 ≤ 1.06 → **C级**
- 1.06 < 评级系数 ≤ 1.18 → **D级**
- 评级系数 > 1.18 → **E级**

**CII评级阈值（MEPC.328(76)附则IX第6条）**：

| 评级 | 评级系数范围 | 含义 |
|------|------------|------|
| **A** | ≤ 0.80 | 优秀 |
| **B** | 0.80 < x ≤ 0.94 | 良好 |
| **C** | 0.94 < x ≤ 1.06 | 中等 |
| **D** | 1.06 < x ≤ 1.18 | 较差 |
| **E** | > 1.18 | 不合格 |

**CII评级后果（MEPC.328(76)附则IX第8条）**：
- 连续三年D级，或上一年度E级 → 需提交**整改行动计划（CAP）**
- CAP需在SEEMP Part III中记录，经船旗国/认可组织批准
- CAP应包含：问题分析、纠正措施、实施时间表、验证方法
- 2023年为CII实施第一年，仅要求记录，不触发CAP

**CII年度折减系数（所需年度CII参考值）**：
- 2023年：基准线 × 0.97
- 2024年：基准线 × 0.94
- 2025年：基准线 × 0.91
- 2026年：基准线 × 0.88

**CII修正系数（MEPC.328(76)附则IX第5条）**：

| 系数 | 适用 | 说明 |
|------|------|------|
| fi | 冰级船舶 | 冰级装载修正，按冰级符号取值 |
| fm | IA Super/IA冰级 | 冰区航行修正 |
| fc | 化学品船 | 货舱容积修正 |
| fi,VSE | 自卸散货船 | 自卸设备修正 |
| FC electrical | 电力推进 | 电力/燃料电池修正 |
| FC boiler | 锅炉 | 锅炉修正 |
| FC others | 独立发动机 | 其他独立发动机修正 |

**航次调整（MEPC.328(76)附则IX第7条）**：
以下情况可申请航次调整，不计入CII计算：
1. 搜救行动（SAR）
2. 为避免不安全情况的偏差
3. 恶劣天气（有义波高、谱峰周期、平均风速达到标准，按船长分档）
4. 冰区航行
5. 其他经主管机关认可的情况

**恶劣天气标准（按船长分档）**：
- 船长 < 100m：有义波高 ≥ 3.0m，或谱峰周期 ≥ 9.0s，或平均风速 ≥ 12.0m/s
- 100m ≤ 船长 < 200m：有义波高 ≥ 3.5m，或谱峰周期 ≥ 10.0s，或平均风速 ≥ 13.0m/s
- 船长 ≥ 200m：有义波高 ≥ 4.0m，或谱峰周期 ≥ 11.0s，或平均风速 ≥ 14.0m/s

**试验碳强度指标（用于航次评估）**：
| 指标 | 公式 | 说明 |
|------|------|------|
| EEPI | 航次能效性能指标 | 基于EEDI公式的航次版本 |
| cbDIST | 基于载重吨和距离的碳强度 | CO2/(dwt·n mile) |
| cIDIST | 基于容积吨和距离的碳强度 | CO2/(GT·n mile) |
| EEOI | 能效运行指数 | CO2/(货运量·n mile) |

**与本知识库的关联**：
- CII的核心是**降低单位运输工作量的CO2**，本知识库第6章优化规则直接降低燃油消耗→降低CO2排放
- 本知识库第8.8节碳排放估算公式可用于CII计算
- 本知识库第5章诊断规则可识别导致CII评级下降的低效工况

### 12.4 DCS（燃油消耗数据收集系统）

**法规依据**：IMO MEPC.278(70) 2016年通过，2018年3月1日生效

**适用范围**：5000总吨及以上的国际航行船舶

**需收集的数据（MEPC.278(70)附则VIII）**：

| 数据项 | 说明 |
|--------|------|

| 总吨/净吨 | 船舶吨位 |
| 载重吨 | dwt |
| 主机额定功率 | kW |

| EEDI（如适用） | 能效设计指数 |
| 冰级符号 | 如适用 |
| 燃油消耗量 | 按燃油类型分别记录（HFO/MGO/LNG等） |

| 航行小时数 | 海上航行时间 |
| 航次信息 | 出发港、到达港 |

**报告流程（MEPC.278(70)第22A条）**：
1. 船舶每日记录燃油消耗数据（燃油日志）

**与本知识库的关联**：

- 本知识库第4章传感器监测体系可支撑DCS数据的自动化采集

## 13. 碳排放核算与能效指标

### 13.1 燃油碳排放因子（IMO默认值）

| 燃油类型 | 碳排放因子 (gCO2/g燃油) | 密度 (t/m³) | 备注 |
|---------|----------------------|------------|------|
| 柴油/汽油 (Gasoline/Diesel) | 3.206 | 0.84 | MGO/MDO |
| 轻燃油 (LFO) | 3.151 | 0.92 | - |
| 重燃油 (HFO) | 3.114 | 0.95 | 船用主力燃料 |
| 液化石油气-丙烷 (LPG Propane) | 3.000 | - | - |
| 液化石油气-丁烷 (LPG Butane) | 3.030 | - | - |
| 液化天然气 (LNG) | 2.750 | - | 甲烷为主 |
| 甲醇 (Methanol) | 1.375 | - | 低碳燃料 |
| 乙醇 (Ethanol) | 1.913 | - | - |
| 乙烷 (Ethane) | 2.927 | - | - |

> **来源**：MEPC.328(76)附则IX第3条；能效管理计划附录A（上海海事局验证版）

### 13.2 CO2排放量计算

**方法一：基于燃油消耗量**

```
CO2排放量 (kg) = 燃油消耗量 (kg) × 碳排放因子 (gCO2/g)
```

示例（12K98ME-C7，100%负荷，HFO）：
- 燃油消耗 = 12973.09 kg/h（台架实测，第229页）
- CO2排放 = 12973.09 × 3.114 = **40,400 kg/h = 40.4 吨/小时**

**方法二：基于SFOC和功率**

```
CO2排放率 (gCO2/kWh) = SFOC (g/kWh) × 碳排放因子 (gCO2/g)
```

示例（75%负荷，经济运行区间）：
- SFOC = 168.64 g/kWh（校正值）
- CO2排放率 = 168.64 × 3.114 = **525.2 gCO2/kWh**

对比100%负荷：
- SFOC = 175.39 g/kWh
- CO2排放率 = 175.39 × 3.114 = **546.2 gCO2/kWh**

> **结论**：75%经济负荷比100%负荷的单位功率CO2排放低 **3.8%**，与SFOC改善幅度一致。

### 13.3 EEOI（能效运行指数）

**定义**：单位运输工作量的CO2排放量，用于单航次或年度能效评估

**计算公式**：

```
EEOI = (Σ 燃油消耗量_j × 碳排放因子_j) / (货运量 × 航行距离)
```

单位：gCO2/(dwt·n mile) 或 gCO2/(TEU·n mile)

**计算步骤**：
1. 统计航次内各类型燃油消耗量（kg）
2. 乘以对应碳排放因子，得到CO2总排放量（g）
3. 除以货运量（dwt）× 航行距离（n mile）
4. 得到EEOI值

**影响EEOI的因素**：
- 主机负荷与SFOC（本知识库第2章）
- 航速（功率≈航速³，降速节油显著）
- 船体污底（增加阻力，本知识库第5.5节）
- 海况/风/流（增加附加阻力）
- 货运量（满载 vs 压载）

### 13.4 EEDI（能效设计指数）

**定义**：新船设计阶段的能效指标，单位运输工作量的CO2排放量

**与EEXI的区别**：
- EEDI适用于**新船**（2013年以后建造）
- EEXI适用于**现有船舶**（2023年起）
- 计算公式类似，但EEXI使用限制后功率

### 13.5 主机优化的CO2减排量化

基于本知识库第3章Pmax-油耗定量关系，可量化优化措施的CO2减排效果：

| 优化措施 | SFOC改善 | CO2减排率（HFO） | 年减排量估算* |
|---------|---------|----------------|-------------|
| Pmax提升5 bar | 1.0~1.5 g/kWh | 0.6~0.9% | 210~315吨 |
| Pmax提升10 bar | 2.0~3.0 g/kWh | 1.1~1.7% | 385~595吨 |
| 气缸平衡+Pmax提升 | 0.5~1.0 g/kWh | 0.3~0.6% | 105~210吨 |
| 自动调谐综合 | 0.5~3.0 g/kWh | 0.3~1.7% | 105~595吨 |
| 从100%→75%负荷运行 | 6.75 g/kWh | 3.8% | 1,335吨 |

> *年减排量估算基于：年运行6000小时，平均功率50000kW，HFO碳排放因子3.114
> **来源**：本知识库第3章MAN官方数据 + 第2章台架数据计算

### 13.6 航速优化的节油与减排

**功率-航速关系**（近似立方定律）：

```
P2/P1 = (V2/V1)³
```

**示例**：航速从100%降至90%：
- 功率需求 = 0.9³ = 0.729（降低27.1%）
- 燃油消耗近似降低27%（考虑SFOC随负荷变化略有修正）
- CO2排放同步降低约27%

**航速优化建议**（结合本知识库第2章SFOC曲线）：
- 降速运行时，主机负荷降低，需关注是否进入低负荷低效区（<50%MCR）
- 最优经济航速对应主机负荷约70%~85%MCR
- 需结合船期约束和CII目标综合决策

## 附录：知识库使用说明

### 智能体推理流程建议

1. **数据输入**：接收实船传感器时序数据（转速、功率、Pmax、Pcomp、排气温度、SFOC、航速、航程、燃油消耗量等）
2. **基准对标**：将当前工况数据与本知识库第2章台架基准数据对比
3. **诊断执行**：按第5章诊断规则库逐条匹配，识别低效工况/性能衰减/气缸不平衡
4. **优化输出**：按第6章优化规则库生成优化建议（负荷调整/Pmax调谐/气缸平衡/正时调整/航速优化）
5. **维护建议**：按第7章维护规则输出性能恢复措施
6. **量化评估**：用第3章定量关系和第8章公式计算节油量，用第13章公式计算CO2减排量和CII影响
7. **法规合规检查**：按第12章法规体系检查SEEMP/EEXI/CII/DCS合规性，生成合规报告

### 知识库局限性声明

- 本知识库基于**工厂台架试验数据**，实船油耗需考虑船体阻力、海况、污底、燃油品质等修正
- 台架数据无**船舶航速**信息，航速-功率映射需结合实船数据建立
- 第12-13章能效法规与碳排放内容基于 `ME能耗管理/` 目录4份文件OCR识别内容整理（MEPC.346(78)/MEPC.328(76)/MEPC.278(70)+中国籍船舶SEEMP模板）；EEXI/CII基准线和折减系数随IMO决议更新，使用时需核实最新版本
- 碳排放因子采用IMO默认值，实际计算应使用燃油实际检测报告中的碳排放因子
- 部分阈值表（701-02 Guidance Value Automation）为扫描图片，未完全数字化，建议实船使用时以具体船舶报警设定值为准
- EEXI/CII基准线和折减系数随IMO决议更新，使用时需核实最新版本
